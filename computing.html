Windows · Performance

JD Frag Engine

A small Windows tool in C for JD Arena players running Free Fire on a PC emulator. It sets the FPS cap to match the screen, keeps the emulator on the fast cores of newer Intel laptops, and puts everything back when the match ends. It stays on the fair-play side by design: it never touches game or emulator memory and has no macros or aim assist. Updates are checked against a SHA-256 hash before they install.

JD Esports Arena

How the hard parts work

Players trust this site with real money, so most of the engineering went into making mistakes and cheating difficult.

Points follow real money

A phone app forwards "money received" alerts to the backend. A mod can only add points when a player's proof matches one real payment, and each payment can pay only once. Anything unclear goes to the owner.

Prizes can't be paid twice

Payouts run on the server, not in the browser. Only registered squads can be paid, never more than the prize pool, and each squad only once. Every payment is logged, and loads and withdrawals ask for the player's own PIN.

Free cards resist farming

One follow-route card per player and per TikTok account, ever. A database lock stops two mods approving the same account at the same moment, and only approved claims reserve a handle, so nobody can block someone else's.

Alerts land on the right page

A scheduled job spots each new TikTok video and alerts every player. Tapping an alert opens the exact page it is about, and the database only accepts video links in one strict format, so a bad row can't send people somewhere else.

Load test · k6

21,781 transfers, 200 users at once

I load-tested my jd-ledger wallet API in CI, with transfers fighting over the same hot accounts and duplicate retries. The first run found a real bug: requests queued for database connections inside worker threads, which starved the threads and caused 60-second timeouts. After the fix: 434 requests a second, 0 errors, 0 deadlocks, every duplicate applied exactly once, and 12 of 12 money invariants held.
